## Page-by-page

### 1. Home — `/`
- **Purpose:** first impression + booking entry.
- **Sections (order):**
  1. Header.
  2. **Hero** (1240×880 box, inset 100 px each side on desktop; full-width on tablet/mobile): photo of the infinity pool deck with net loungers, palms and rice fields (`home-hero-pool-ricefield`). Overlaid, centred: logotype "podpadi" / "design spaces" (Comfortaa Bold, pale mint `#C6E0E0`, letter-spaced, soft drop-shadow), tagline "Step Into Tranquility" (DIN Next 22 px bold, white, 3D stacked text-shadow), **HotelRunner search widget** (white bar: date range, rooms & guests, grey "Search" button), share buttons (FB / WhatsApp / Copy link).
  3. Footer (invisible).
- **Content to retain:** logotype, tagline, booking entry, hero photo. The meta description holds the only "about the place" copy on Home (Mount Agung views, rice fields, peaceful retreat).
- **Assets:** `home-hero-pool-ricefield` (original 6720×4480, 24.7 MB).
- **Interactive:** date picker (opens calendar — verified), guest dropdown (Room 1 / Adults / Add room / Close / Search — verified), Search → navigates to `/booking-engine#/search?search={json}` (verified).
- **Responsive:** tablet = 980 px canvas with horizontal scroll; mobile = hero cropped to ~420 px tall, widget stacks vertically; large empty white area below hero on mobile.
- **SEO:** good meta description; title "HOME | podpadiubud"; LD+JSON LocalBusiness + WebSite.
- **Risks:** homepage says nothing about rooms, location or reviews in visible text.
- **Recommendation:** Phase 2 home should surface (concisely) the villa types, location, a few reviews, and a clear booking/enquiry CTA.
